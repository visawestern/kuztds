## Поведение

- `Stream.SkipClicks` (`skip_clicks`) — осознанно узкий флаг: визит
  обслуживается как обычно (маршрут, макросы, ответ), но строка клика не
  пишется.
- Следствия задокументированы: визита нет в Logs/отчётах/стоимости; постбек по
  такому визиту не к чему привязать (`RecordPostback` требует событие по cid),
  поэтому конверсий по служебным потокам не будет.
- Групповой default (без выбранного потока) всегда логируется; флаг только на
  потоке, как и в эталоне для служебных потоков.
- UI: чекбокс в дровере потока с честным описанием последствий; пример —
  выключенный `service_preview`, доки EN/RU, README.
- Отчёты и схема не менялись: событий для такого потока просто нет.
